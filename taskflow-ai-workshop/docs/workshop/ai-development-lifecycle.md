# AI-assisted development lifecycle

1. **Understand** — restate the requirement and identify ambiguity.
2. **Plan** — list files, design choices, edge cases, and tests.
3. **Implement** — make a small, reviewable change.
4. **Test** — run targeted tests, then the broader suite.
5. **Review** — inspect the diff, security, edge cases, and test coverage.
6. **Deliver** — document the change, commit it, and open a pull request.

Copilot is an assistant, not an approval mechanism. Developers remain responsible for validating generated code and reviewing tool actions.
