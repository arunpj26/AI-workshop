# AI-Assisted Engineering Workshop

A hands-on, five-session workshop (about 3h40) on using GitHub Copilot to take a real feature from a Jira story to a review-ready pull request, using the TaskFlow Spring Boot app.

## What attendees get
- **Advanced prompting:** structured, reusable prompts for requirement analysis, planning, test generation and review.
- **Repository customization:** repository-wide and file-specific Copilot instructions for Java, frontend and Playwright code.
- **Custom agents, skills and hooks:** role-based agents (planner, developer, tester, reviewer, PR creator), reusable skills and guardrail hooks.
- **MCP integration:** a Jira connection through the Atlassian MCP server, plus guidance on security, least privilege and prompt injection.
- **End-to-end practice:** implementing the task priority filter with backend tests, headed Playwright E2E checks, code review and PR preparation, with human approval at each step.
- **Reusable assets:** a starter repository with prompts, instructions, agents and skills you can adapt for your own projects.
